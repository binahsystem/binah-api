# BINAH API

Bem-vindo à API oficial da plataforma BINAH.

## Sobre o projeto

A BINAH é uma plataforma inteligente de gestão para restaurantes, criada para integrar estoque, compras, produção, controladoria e indicadores em um único ambiente.

Nosso objetivo é transformar dados operacionais em informações estratégicas para apoiar decisões mais rápidas, reduzir desperdícios e aumentar a rentabilidade do negócio.

## Tecnologias

- Python
- FastAPI
- PostgreSQL
- Git
- GitHub
